# Windows 人工验收

## 当前候选

使用支持 `provider.comments` 的 YAQMC 宿主和本仓库构建的 `org.yaqmc.providers.music-0.2.2.yaqmc-plugin`。宿主与插件分别构建；不需要启动 Backend、Node.js 服务或独立 API 进程。历史版本的安装说明见测试记录，`<YAQMC>`、`<Downloads>` 是路径占位符。

## 准备

1. 关闭旧便携版，正常双击当前 EXE。不要使用开发者 QA 配置或远程调试参数登录真实账号。
2. 在插件页面先停用已安装的 `org.yaqmc.providers.music`，再安装当前同版本包并启用。
3. 审核权限后授权；这是未签名候选，如宿主要求开发者模式，应由你在界面明确开启。
4. 不需要卸载私有数据。删除数据会清理插件设置和账号，只有你确定需要时才执行。
5. 打开设置中的“当前音乐服务”，分别管理平台账号。联合 Provider 没有额外的统一登录账号。

## 平台与模式

- `isolated`：Spotify、NetEase Cloud Music、KuGou Music、QQ Music，共四个。
- 改为 `aggregate`：四个仍保留，新增 YAQMC All Music Platforms，共五个。
- 选项应在设置成功后自动刷新，允许短暂异步加载，不需要手动刷新页面。
- 依次切换 isolated → aggregate → isolated，确认联合项移除且没有残留的不可用项。
- 在两种模式各重启一次，确认模式、平台和各自的音质偏好保留。

## 真实登录

### Spotify

1. 使用自己的 Spotify Developer 应用，在 Dashboard 登记完全一致的回调：
   `http://127.0.0.1:43821/oauth/spotify/callback`。
2. 在插件设置中填写 Client ID，不填写 Client Secret。
3. 在 Spotify 账号页面完成浏览器 PKCE 授权。
4. 确认登录完成后仍显示已认证，重启后会话能恢复。
5. 检查搜索、可用试听、已保存歌曲和本人/协作歌单。
6. 不提供 Client ID 时，登录/搜索应显示配置错误，而不是要求启动本地服务。

Spotify 完整歌曲音频和完整音质分档不由 Web API 提供。本插件只播放平台确实返回的试听地址，不能把不存在的试听当成已播放。

### 网易云、酷狗

两个平台分别使用其官方 App：

1. 打开对应账号页面并创建二维码。
2. 未扫码时观察至少 30 秒，二维码不应几秒后消失；提示应指向当前平台而不是 QQ。
3. 扫码并在手机确认，分别观察等待扫码、等待确认、已认证状态。
4. 取消后重新打开登录，应获得新二维码；旧轮询不能覆盖新尝试。
5. 重启后检查会话恢复，再检查退出登录只清除当前平台，不影响另两个平台及 QQ。

自动化已验证生产二维码的创建、显示、未扫码等待和取消，但没有代替你完成真实扫码确认。

## 搜索、详情与播放

两种模式都检查下列样本；聚合结果中选对来源，不要把匿名 QQ 首条失败当作所有平台失败。

| 平台 | 查询 | 本轮测试录音 |
| --- | --- | --- |
| 网易云 | 屋顶 | ID `5257138` |
| 酷狗 | Monkeys Spinning Monkeys | Hash `F09B7FAE3D1A3860C10738EBB33DCBBA` |

1. 确认正常 20 条结果，滚动追加第二页，快速替换查询后只保留最新结果。
2. 打开歌曲详情，确认封面、标题、歌手和时长正确。
3. 用界面播放、暂停、恢复、拖动进度；人工确认确实有声音。自动化的零音量播放时钟不是听感验收。
4. 打开歌词：网易云样本应有歌词；酷狗纯音乐样本没有已核对匹配的歌词，应显示清晰的无歌词提示，不显示无关歌词。
5. 播放网易云后切换目录到酷狗，再调当前歌曲音质；仍应操作正在播放的网易云录音，封面不能换成酷狗内容。
6. 在联合目录从搜索行直接播放网易云/酷狗，再切换当前音质；检查来源路由没有丢失媒体 ID，播放器栏与歌词页封面均显示，而不只是歌曲详情有封面。
7. 内置 QQ 检查搜索、详情、播放和既有账号行为，不修改 QQ 凭据作排查捷径。

酷狗本轮匿名 `晴天` 和 `两只老虎` 录音被上游权益拒绝。这是拒绝路径，不是成功播放；真实账号能否播放要单独验证。成功样本也不证明所有歌曲、地区或会员音质都可用。

## 音质与账号库

- 不同平台/Profile 设置不同偏好，重启后各自恢复；当前曲目切换不应改写长期偏好。
- 网易云样本当前可返回高品质；酷狗样本请求高品质时观察请求档与实际标准档、权益降级说明。
- 已确认拒绝的档位可能禁用；不要强制绕过界面和权益限制。
- `automatic` 当前请求标准档，不是“最高会员音质”保证。登录不应虚构已确认的会员套餐。
- 用真实账号分别检查可用及被拒绝的无损/Hi-Res/母带路径；Spotify 仅自动/标准试听，酷狗不支持母带。
- Spotify：已保存歌曲、歌单及本人/协作歌单曲目；无权限歌单要拒绝但不能清掉整个会话。
- 网易云：喜欢的歌曲、账号歌单和歌单曲目。
- 酷狗：账号歌单和曲目；喜欢的歌曲接口未支持，应明确 unsupported，而不是伪造空结果。
- 有足够数据时检查分页与重启后重新打开；退出后不再显示依赖旧认证的数据。

## 功能边界与发布门槛

外部平台当前支持歌曲搜索/详情与相应歌词；首页、发现以及专辑/歌手/歌单目录未实现。首页不支持不能阻止进入搜索和歌曲详情，不支持的操作不能报告成功。账号歌单读取和公共歌单目录是不同能力。

在真实登录、账号库/会话恢复、可听播放、两种模式、音质与 QQ 回归全部人工通过，且剩余功能限制被修复或由你明确接受前，禁止 Tag/Release。不因为生成候选包而升版。

失败记录只需平台、模式、操作、可见错误码、重试/重启结果；不要提供 Cookie、Token、密码、Client Secret 或 OAuth 回调查询参数。

## 评论与回复验收

- 网易云分别读取热门、最新评论，连续翻页并确认最新为时间倒序。
- 无歌词的歌曲仍可打开评论，横屏使用侧栏、竖屏使用底部面板。
- 展开至少三条回复的线程，用小页大小验证跨页仍为全局最新优先、没有重复 ID。
- 超过 500 条的线程明确提示排序上限；普通断网仍保留已加载内容并提供重试。
- 升级或更换歌曲、排序、父评论、账号配置、页大小后不复用旧游标。
- 评论只读，不提供发评、点赞写操作；头像失败显示占位，正文作为纯文本显示。
